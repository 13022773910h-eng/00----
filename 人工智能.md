# Python 进阶

## Anaconda 的使用

### 查看版本

```python
conda --version
# 简写
conda -V
```

### 查看虚拟环境

```python
conda env list
# 或
conda info --envs
```

### 创建虚拟环境

![image-20261009150844817](C:/Users/hw/AppData/Roaming/Typora/typora-user-images/image-20261009150844817.png)

![image-20261009151046679](C:/Users/hw/AppData/Roaming/Typora/typora-user-images/image-20261009151046679.png)

第二个命令补全了所有的基础包

```py
conda create -n gupao python=3.6
conda create -n gupao python=3.6 anacond
```

### 切换虚拟环境

![image-20261009150817148](C:/Users/hw/AppData/Roaming/Typora/typora-user-images/image-20261009150817148.png)

```python
# Windows
conda activate myenv

# Linux/Mac（旧版conda）
source activate myenv
```

### 删除虚拟环境

```python
conda remove -n myenv --all
```

### 克隆虚拟环境

```python
conda create -n newenv --clone myenv
```

### 在 IDE 中添加虚拟环境

![image-20261009151009972](C:/Users/hw/AppData/Roaming/Typora/typora-user-images/image-20261009151009972.png)

### 安装包

```python
# 安装包
conda install numpy

# 指定版本安装
conda install numpy=1.24

# 卸载包
conda remove numpy

# 查询当前环境已安装包
conda list

# 搜索包
conda search opencv
```

# 更新conda本身
